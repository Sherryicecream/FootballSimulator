# Football Simulator v1 发布说明

状态：体验升级验收候选版  
日期：2026-09-21  
对应计划：docs/superpowers/plans/2026-09-13-career-experience-upgrade.md

## 版本定位

本版本完成从青训、职业合同、转会与留洋、国家队、俱乐部赛事到退役回顾的完整生涯闭环，并补充了节点式推进、历史存档、八国足球世界、确定性叙事和可选 AI 润色。

package.json 当前仍使用内部版本号 0.0.0；本文件的“v1”是体验升级交付标识，不表示已经发布到公共应用商店。

## 新功能

- 月度节点式生涯推进：默认入口是“推进到下一节点”，保留逐月推进作为次要入口；不恢复玩家侧周推进或快速跳过。
- 训练与比赛反馈：训练负荷、疲劳、健康、比赛表现和能力变化形成可保存的反馈链，合理负荷有助于发挥，过高或过低都会留下可解释影响。
- 更丰富的比赛结果：常规小比分、大比分、平局和失利均可能出现，比赛表现不再长期收敛到保守结果。
- 青训毕业与职业合同：多份要约比较、能力天花板、兴趣匹配、承诺兑现与拒签路线均可回顾。
- 职业赛事深度：联赛、国内杯、荣誉、升级/降级、赛季阵容、球员统计和球队赛季表现相互关联。
- 八国足球世界：240 支虚构俱乐部、八国联赛、洲际机会、世界动态、转会传闻与跨国转会；国家队不会参与俱乐部转会。
- 跨赛季人物连续性：俱乐部核心人物、姓名、位置、能力特点和人物关系可以延续；不同俱乐部和国家队边界保持独立。
- 国家队赛事：国家队球员可以经历亚洲杯、世界杯和友谊赛等国家队节点，国家队事实进入职业履历和退役回顾。
- 历史存档：进行中的存档尽可能保留完整状态；结束存档保留简介、人物评价、人物经历、转会记录、球员履历、数据统计和荣誉象征，并提供历史阅读入口。
- 生涯回顾：退役后提供本地确定性总结、八维评价、幕后档案、荣誉奖项、关键数据、独特比赛记录和可回放的生涯节点。
- 受控 AI 叙事：AI 只润色已经发生的事实，不决定比赛、属性、关系、阶段或存档；无服务、超时、离线或事实冲突时回退本地文本。
- 多周目差异：种子、事件家族、选择后果和故事组合保持确定性，同时提供不同生涯之间的差异。

## 使用方式

在项目根目录执行：

    pnpm install
    pnpm dev

打开本地开发地址后，创建生涯即可开始。种子输入是可选功能；不填写时使用随机生涯。AI 润色需要额外启动并配置 OpenAI 兼容服务，未配置时所有本地确定性内容仍可正常使用。

## 交付与安装

- GitHub Pages 在线版：<https://sherryicecream.github.io/FootballSimulator/>
- Windows 用户可双击根目录的 `启动足球模拟器.cmd`。
- Android 可以使用 HTTPS 在线版，或通过同一 Wi-Fi 下的局域网地址访问电脑开发版本。
- 完整操作说明见 [docs/INSTALLATION.md](INSTALLATION.md)。

## 已知限制

- 20 分钟快速路径目前只有工具负担分析和自动化路径证据；真人测试记录需按 docs/testing/experience-playtest-protocol.md 和 docs/testing/experience-playtest-report-TEMPLATE.md 补充，不能用批量模拟时间代替。
- 当前俱乐部为虚构数据，不含现实俱乐部授权、真实球员或真实转播资料。
- 非玩家球队使用紧凑赛季结算，保存冠军、升降级、平均强度和必要世界事实，不保存每支非玩家球队的逐场个人明细。
- AI 润色依赖本地或外部 OpenAI 兼容服务；离线时 AI 不可用，但本地回顾、比赛、存档和推进仍可用。
- PWA 当前采用手动刷新获取新版本，不提供复杂的后台更新策略。
- 10,000 季平衡命令属于开发验收工具，可能占用较高 CPU，不是玩家运行路径。
- 当前版本不承诺云端同步、跨设备存档合并或导入其他版本的完整生涯档案。

## 真人体验验证

真人测试需要至少覆盖两名非资深足球游戏玩家、两名有体育模拟经验的玩家，并建议达到五份记录。测试结果必须区分：

- 已由真实测试者观察到的结果；
- 自动化或工具辅助结果；
- 待招募补充的结果。

在真人记录完成前，本版本可以称为“自动化验收通过的体验升级候选版”，不能宣称 20 分钟目标已经通过真人验证。
