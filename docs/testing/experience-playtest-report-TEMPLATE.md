# 生涯体验真人测试记录模板

> 用途：记录 G6 Task23 的真人体验证据。此模板不替代自动化测试，也不把工具运行时间、批量模拟时间或必读字符数换算为真人用时。

## 使用规则

- 每位测试者独立填写一份记录；建议至少 5 份。
- 测试者完成手机和桌面各一段完整生涯；手机使用 412×915 或相近尺寸，桌面使用 1440×900 或相近尺寸。
- 每段从点击“创建生涯”开始计时，到首次显示可读终局总结或历史存档阅读页结束。
- 不收集存档、不上传个人信息、不要求安装 PWA。测试记录只保留匿名编号。
- 没有真实测试者时，填写“待招募补充”，不得用自动化结果代替真人评价。

每个问题只选择一个主要原因：

- A：测试环境或说明不清，可以通过重试或改进协议解决。
