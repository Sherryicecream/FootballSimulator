# 安装与启动

足球生涯模拟器提供三种使用入口：GitHub Pages 在线版、Windows 双击启动，以及同一 Wi-Fi 下的 Android 局域网访问。

## 1. 在线版：电脑或 Android 直接打开

地址：<https://sherryicecream.github.io/FootballSimulator/>

首次部署或更新需要等待 GitHub Actions 完成。在线版使用 HTTPS，适合电脑和 Android 长期使用，也支持浏览器提供的 PWA 安装入口。

在线版的存档保存在当前浏览器设备中，不会自动同步到其他设备；不要清理浏览器站点数据，除非已经导出或不再需要存档。

## 2. Windows 双击启动

### 环境要求

- Windows 10/11；
- Node.js 24.16.0 或更高版本；
- pnpm 11.9.0 或更高版本；
- 项目目录已经下载到电脑。

如果系统尚未启用 pnpm，可以在 PowerShell 中执行一次 `corepack enable`。

### 操作步骤

1. 打开 `FootballSimulator` 项目根目录。
2. 双击 [启动足球模拟器.cmd](../启动足球模拟器.cmd)。
3. 首次启动会自动执行依赖安装，等待安装完成。
4. 浏览器会打开 `http://127.0.0.1:5173/`。
5. 启动器窗口会显示手机访问所需的局域网地址；保持服务器窗口开启即可继续使用。

启动器不会修改防火墙、启动 AI 服务或写入生涯存档。停止时关闭最小化的服务器窗口即可。

### 命令行备用方式

在项目根目录执行：

```text
pnpm install
pnpm dev
```

需要让手机访问时使用：

```text
pnpm dev:lan
```

## 3. Android 局域网访问

此方式适合测试本地开发版本，电脑和手机必须连接同一 Wi-Fi。

1. 在 Windows 双击启动器。
2. 查看启动器显示的 `Phone/LAN` 地址，例如 `http://192.168.x.x:5173/`。
3. 在 Android Chrome 地址栏输入这个地址。
4. 如果无法访问，确认 Windows 网络允许 Node.js 在“专用网络”通信，并检查电脑与手机是否在同一个路由器网络。

局域网入口使用 HTTP，浏览器不一定显示“安装到主屏幕”；需要稳定安装 PWA 时请使用上面的 HTTPS GitHub Pages 地址。局域网地址可能因 Wi-Fi、网卡或 VPN 变化，每次以启动器显示的地址为准。

## 4. Android 安装到主屏幕

1. 用 Android Chrome 打开 GitHub Pages 地址。
2. 打开浏览器菜单，选择“安装应用”或“添加到主屏幕”。
3. 从主屏幕启动“生涯模拟器”。

不同 Android 厂商的菜单名称可能略有区别。若没有安装选项，先确认使用的是 HTTPS 在线地址，并刷新页面等待资源加载完成。

## 5. AI 润色说明

本地确定性比赛、推进、存档和生涯回顾不依赖 AI。在线 GitHub Pages 版本不会自动启动本地 AI 服务；AI 润色需要另外配置 OpenAI 兼容服务，失败或离线时会回退到本地总结。

不要把 API key 写入仓库、提交到 Git，或放入公开的 Pages 构建变量中。

## 6. 常见问题

### 浏览器显示无法连接

确认服务器窗口仍在运行，并重新使用启动器显示的地址。若 5173 端口已被占用，可以关闭占用该端口的旧开发服务器后重试。

### Windows 阻止启动器

确认启动器位于项目根目录，并从可信来源重新下载项目。启动器是普通 `.cmd` 文件，不需要管理员权限。

### GitHub Pages 显示 404

先检查 GitHub Actions 是否成功，再在仓库 Settings → Pages 中将发布来源设置为 GitHub Actions。首次部署完成后使用带 `/FootballSimulator/` 的完整地址，不要删掉仓库路径。

### 存档不见了

先确认使用的是同一个浏览器、设备和站点地址。GitHub Pages 与局域网地址属于不同站点来源，存档不会自动互通；清理浏览器数据也可能删除本地存档。
