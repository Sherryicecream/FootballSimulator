# Football Simulator Roadmap

本文件是项目阶段状态的唯一入口。产品长期规则见根目录 `spec.md`，当前详细机制见唯一活动设计文档，当前实施步骤见唯一活动计划。过期计划不再作为代理输入。

## 当前状态

- 稳定基线已经恢复：未完成的毕业/合同契约已移除，周状态投影、事件冷却、批量账本和待决事件恢复均有回归测试。
- 首个青训赛季纵向切面已经完成：网页使用 v2 月度流程，可处理事件中断、训练设置、月报、刷新恢复与赛季总结；桌面和移动端均可完成整季。
- 1,000 赛季校准报告全部完成：中位 22 场、12 次决策、单项成长 P90 为 3、重伤率 1%、一线队关注 17%、正式出场 1.5%、放弃 1%、场均总进球 2.18。
- 当前活动设计：`docs/superpowers/specs/2026-08-30-youth-graduation-contracts-design.md`。
- 当前活动计划：尚未制定，待 M5 设计获批准后编写。
- 当前目标：实现青训毕业与首份职业合同，把单个青训赛季扩展为可连续推进的青训生涯。

## 阶段门禁

每个里程碑必须同时满足：

1. 形成可运行的纵向结果，而不是只新增契约或空目录。
2. 单元、集成和相关 E2E 测试通过。
3. 类型、代码规范、格式和构建检查通过。
4. 新旧存档行为明确，必要时提供迁移。
5. 核心模拟规则具有批量统计或明确不变量。
6. 完成后更新本文件状态，再开始下一里程碑。

## 文档规则

- `spec.md`：唯一长期产品基准。
- `docs/ROADMAP.md`：唯一进度入口。
- `docs/superpowers/specs/`：保留当前设计及带有 superseded 标识的历史设计。
- `docs/superpowers/plans/`：只允许存在一个当前活动计划。
- 产品决策不得只写在实施计划或代码注释中。
