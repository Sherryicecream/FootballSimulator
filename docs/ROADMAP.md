# Football Simulator Roadmap

本文件是项目阶段状态的唯一入口。产品长期规则见根目录 `spec.md`，当前详细机制见唯一活动设计文档，当前实施步骤见唯一活动计划。过期计划不再作为代理输入。

## 当前状态

- 稳定基线已经恢复：未完成的毕业/合同契约已移除，周状态投影、事件冷却、批量账本和待决事件恢复均有回归测试。
- 首个青训赛季纵向切面已经完成：网页使用月度流程，可处理事件中断、训练设置、月报、刷新恢复与赛季总结；桌面和移动端均可完成整季。
- M5 青训毕业与合同已经完成：存档升级为 v3（生涯阶段机、合同、经纪人倾向、赛季历史），支持休赛期结算、连续赛季、补救路线重入、毕业资格评估、2–4 份要约比较与首份职业合同签署；签署后生涯进入"职业合同期"终态，等待 M6。
- 1,000 次三连季批量校验全部完成：完成率 100%；三季内毕业率 34.2%，18 岁前毕业 7%，首约层级与能力相关系数 0.57，拒签全部要约 13.8%，承诺类型三分布均 ≥12%；首季指标保持中位 22 场、10 次决策、单项成长 P90 为 3、重伤率 1.1%、场均总进球 2.18。
- 当前活动设计：`docs/superpowers/specs/2026-08-30-professional-season-design.md`（已获批准）。
- 当前活动计划：`docs/superpowers/plans/2026-08-30-professional-season.md`。
- M6 职业队赛季已经完成：v4 存档（职业赛季/阵容/积分榜/承诺对照），同层级 12 队双循环联赛、登场模型（承诺修正、竞争压制、疲劳伤病硬门槛）、赛季结算与承诺归因、续约/自由球员分支；桌面与移动端均可完整体验。
- 1,000 次三连季（青训 + 职业期）批量校验：完成率 100%；青训毕业率 31.5%；职业期承诺兑现率 85.4%、三季内首发级球员 31.4%、每场出场分钟中位 75、重伤球员占比 7%（约每季 2.4%）。
- 当前目标：M6 已收尾；下一阶段 M7 生涯扩展（转会、海外、国家队、巅峰和退役）需先单独设计。

## 阶段门禁

每个里程碑必须同时满足：

1. 形成可运行的纵向结果，而不是只新增契约或空目录。
2. 单元、集成和相关 E2E 测试通过。
3. 类型、代码规范、格式和构建检查通过。
4. 新旧存档行为明确，必要时提供迁移。
5. 核心模拟规则具有批量统计或明确不变量。
6. 完成后更新本文件状态，再开始下一里程碑。

## 文档规则

- `spec.md`：唯一长期产品基准。
- `docs/ROADMAP.md`：唯一进度入口。
- `docs/superpowers/specs/`：保留当前设计及带有 superseded 标识的历史设计。
- `docs/superpowers/plans/`：只允许存在一个当前活动计划。
- 产品决策不得只写在实施计划或代码注释中。
