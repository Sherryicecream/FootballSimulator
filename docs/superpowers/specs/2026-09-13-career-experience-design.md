# 足球生涯体验升级产品设计

> 批准状态：草案。本设计记录已确认的产品默认值和推进方式决策，是 Task 00 的产物。
> 替代：`2026-08-31-experience-upgrade-design.md`（superseded，归入历史）。

## 1. 推进方式决策

**决定：采用方案A——推进到下一决策节点（Advance to Next Node）。**

### 背景

20 分钟全生涯目标与现有逐月推进（14 季 × ~10 次/季 = 140 次操作）不可兼得。曾考虑三种方案：

| 方案 | 操作量 | 评估 |
|------|--------|------|
| 逐月推进+短简报 | ~80-100 次 | 不够 |
| 赛季季度推进 | ~56 次 | 仍不够，事件打断导致次数反弹 |
| **推进到下一节点（选）** | **~25-40 次** | ✅ 可达 20 分钟目标，改动适中 |

### 推进规则

玩家点击"推进到下一节点"→ 模拟器连续推进月份（保持现有月度结算不变）→ 在以下情况之一停下：

1. **有事件待选择**（交互事件/关键时刻/分支故事）
2. **赛季结束**（休赛期/转会窗/毕业评估）
3. **伤病触发**（需要玩家决定治疗/恢复策略）
4. **合同到期/报价窗口** 
5. **国家队征召窗口**
6. **赛季末重要结算**（冠军确认/升降级）

跳过月份不丢失信息：每月的比赛、成长、疲劳变化聚合为一行摘要。玩家可展开查看详情。

### 保留的交互

- "逐月推进"保留为次要入口（小字链接），用于玩家想细看时
- 不可逆决定（签约/退役）保留一步确认
- 事件选择单击生效并防连点

### 模拟引擎不变

- 仍按月结算成长、疲劳、伤病、比赛
- 仍按"每月最多2个互动"的模拟上限筛选事件
- `advanceToNextNode` 是对现有 `advanceOneMonth` 的批量调用 + 停止条件检查
- 一个事务中完成所有跳过月份，不存储中间状态

## 2. 20 分钟计时口径

| 项目 | 口径 |
|------|------|
| 起计时 | 点击"创建球员"后开始 |
| 止计时 | 显示可读的终局总结（规则评价 + 八维 + 幕后档案已渲染） |
| 计入时间 | 强制阅读、选择操作、计算等待、合同/转会谈判过程 |
| 不计入 | AI 异步增强（人生总结加载）、展开的详细档案、展开的完整月报 |
| 不作弊 | 不能通过提前退役、跳过所有选择、排除等待时间、隐藏失败操作来达标 |

**时间预算分配（目标值，T09 实测后校准）：**

| 阶段 | 预算 |
|------|------|
| 创建球员与开局介绍 | ≤ 1 分钟 |
| 常规推进与节点简报 | ≤ 5 分钟 |
| 重要选择及即时反馈 | ≤ 8 分钟 |
| 合同/赛季转换/休赛期 | ≤ 3 分钟 |
| 退役总结阅读 | ≤ 2 分钟 |
| 余量 | 1 分钟 |
| **合计** | **≤ 20 分钟** |

## 3. 模拟默认值

### 3.1 联赛与俱乐部

| 项目 | 默认值 |
|------|--------|
| 覆盖国家 | 中国、英格兰、西班牙、德国、意大利、法国、日本、韩国（8 国） |
| 球队总量 | 240 家（国内 72 + 海外 168） |
| 海外结构 | 每国 2 级 × 12 队 = 24 队/国 |
| 国内结构 | 6 级 × 12 队 = 72 队（现有关保留不变） |
| 赛制 | 每级 12 队双循环 22 轮；胜 3 平 1 负 0 |
| 同分排序 | 净胜球 → 进球数 → 赛季创建时固定抽签序 |
| 升降级 | 相邻级别前 2 升后 2 降；最顶无升、最底无降 |
| 欧洲赛历 | 每年 9 月至次年 5 月 |
| 亚洲赛历 | 每年 3 月至 11 月 |
| 青训赛历 | 每年 9 月至 6 月（不变） |

### 3.2 转会与国家队

| 项目 | 默认值 |
|------|--------|
| 吸引力系数 | 同国 100、非欧洲国家间 70、跨洲际 45（语言修正） |
| 日历桥接 | >90 天空窗期自动添加"长期休整"月份 |
| 国家队大赛 | 抽象亚洲杯（%4==0）/世界杯（%4==2）；保留现有逻辑 |

### 3.3 内容与 AI

| 项目 | 默认值 |
|------|--------|
| 核心故事家族 | 30+ 家族，每家族 ≥3 节点、≥2 收束结局 |
| 每国专属事件 | 6+/国（不是同义句替换，反映该国足球现状） |
| AI 人生总结 | 短版 150-250 字（即时展示），长版 400-800 字（可选展开） |
| AI 关键节点 | 首份合同/重伤/转会/国家队/退役，5 场景独立 prompt |
| AI 失败行为 | 超时 5000ms 回退→作者模板；矛盾检测→丢弃 AI 输出 |
| 无 AI 路径 | 依然具有完整的基础文案体量和游戏内容 |

| 版本 | 新增内容 | 向后兼容 |

## 5. 种子交互

| 项目 | 默认值 |
|------|--------|
| 输入 | 创建页面可选输入，留空则随机生成 |
| 格式 | 十进制非负整数（0-2147483647） |
| 显示 | 创建后只读展示、可复制 |
| 复现 | 同球员设置 + 种子 + 机械/内容版本 + 选择序列 → 相同机械结果 |
| 限制 | 已提交结果不能通过重设种子重抽；种子不用于跨局隐藏修正 |

| 指标 | 定义 | G6 目标 |
