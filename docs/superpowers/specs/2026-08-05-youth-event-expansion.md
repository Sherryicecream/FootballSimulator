# 足球生涯模拟器 — 青年事件扩充与结果展示设计

> **已被取代：** 本文仅保留为事件内容历史。当前事件资格、密度、人物关联和冷却设计以 `2026-08-07-youth-season-vertical-slice-design.md` 为准，不得继续依据本文实施。

## 1. 概述

本文档描述如何扩充青年生涯事件系统，解决现有 7 个事件导致的重复问题，并在事件选择后展示结果。

## 2. 问题分析

### 2.1 事件重复

- 事件池仅 7 个，出现频率高时玩家很快看到重复内容
- 冷却期机制未正确运转（`cooldowns: {}` 硬编码为空）
- 事件概率 10% 偏低，但一旦出现可选项太少

### 2.2 结果缺失

- 选择后直接跳回仪表盘，玩家看不到选择后果

## 3. 解决方案

### 3.1 按维度扩充事件（+9 个，总数 16）

| 维度         |        已有        |    新增    | 事件      |     稀有度      | 效果维度 |
| ------------ | :----------------: | :--------: | --------- | :-------------: | :------: |
| 🏋️ 训练/成长 |      教练表扬      |  额外加练  | common    |   属性↑ 疲劳↑   |
| ⚽ 比赛/竞技 |      位置竞争      |  首秀机会  | uncommon  | 士气↑ 教练信任↑ |
| 👥 关系/团队 |      队友邀请      | 更衣室冲突 | uncommon  | 士气↓ 关系修复  |
| 🏠 生活/场外 | 家人鼓励、平淡一周 | 社交与休息 | common    |  士气↑ 疲劳↑↓   |
| 🏥 健康/伤病 |      轻微不适      |  体能测试  | common    |   体能↑ 疲劳↑   |
| 🧠 心理/士气 |         —          |  信心危机  | uncommon  |  士气↓ 意志↑↓   |
|              |                    |  媒体关注  | rare      |   士气↑ 压力↑   |
| 🎯 发展/前途 |         —          |  球探观察  | rare      | 士气↑ 状态波动  |
|              |                    |  试训邀请  | legendary | 士气↑↑ 生涯转折 |

### 3.2 修复冷却期

- `pickEventForWeek` 从 `save.story` 读取已有冷却期
- 事件选择后更新冷却期并写回

### 3.3 提高事件概率

- 10% → 15%
- 相应减少训练周概率

### 3.4 事件结果展示

- 新增 `EventResultPanel` 组件
- 显示选择内容、效果变化、状态前后对比
- 新增 `FlowStep`：`'event-result'`

## 4. 组件变更

### 4.1 EventResultPanel（新组件）

```
EventResultPanel
├── 事件标题（复用）
├── 已选择的选项（高亮）
├── 效果变化列表
│   ├── 士气 +5  (25 → 30)
│   ├── 教练信任 +3  (35 → 38)
│   └── ...
└── [返回仪表盘] 按钮
```

### 4.2 App.tsx 变更

- 新增 `'event-result'` 步骤
- `handleEventChoice` 改为切换到 `event-result` 而非 `dashboard`
- 传递事件结果信息

## 5. 实施顺序

1. 扩充事件内容（9 个新事件）
2. 修复冷却期追踪
3. 提高事件概率
4. 实现 EventResultPanel
5. 修改 App.tsx 流程
6. 编写测试
7. 运行质量门禁
