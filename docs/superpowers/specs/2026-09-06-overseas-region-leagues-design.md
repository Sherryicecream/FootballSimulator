# 海外联赛区域分组设计（M11 模块 1）

> 状态：按长期清单推进（spec §4 三层世界的活跃层第一步）。
>
> 日期：2026-09-06
>
> 前置：M10 全部完成。当前留洋联赛把欧洲与亚洲虚构俱乐部混入同一张 `pro-overseas-tier-N` 积分榜。

## 1. 目标

海外（留洋）职业赛季的联赛按 `overseasRegion`（europe / asia）分组：留洋日本的球员只在日韩虚构俱乐部之间比赛，留洋欧洲同理。这是日韩英德活跃层世界（spec §4 第二层）的第一步，不改国内联赛、国内杯与任何比赛公式。

## 2. 设计

1. **联赛分组**（application `startProfessionalSeason`）：海外球员的同组资格从"是否海外"细化为"是否海外且 `overseasRegion` 一致"；国内俱乐部不受影响（`overseasRegion` 为空）。
2. **竞赛标识**：海外 `competitionId` 细化为 `pro-overseas-{region}-tier-N`，使比赛事实可区分洲别（比赛关键时刻的重要性判定只依赖 `domestic-cup` 与 `pro-` 前缀，不受影响）。
3. **内容补齐**：亚洲俱乐部从 4 家扩到 12 家（层级 8×3、7×2、6×3、5×2、4×2），使亚洲每个可用层级（4–8）都能按既有"同层优先、±1 层补足、至少 4 队"规则成军；欧洲现有 12 家已满足。
4. **存档兼容**：赛程每赛季重建，无 schema 变更；既有留洋存档在新赛季开始时按新规则分组。

## 3. 测试与验收

- application：亚洲俱乐部开赛 → 联赛俱乐部全部为亚洲；欧洲俱乐部开赛 → 全部欧洲；国内不变。
- content：亚洲层级 4–8 每层按 ±1 规则可组成 ≥4 队（直接断言）。
- 门禁全绿；1,000 季平衡：完成率 100%、世界级 1–5%、国家队 15–30%、毕业率/承诺兑现率与模块 11 基线一致（联赛对手池变化允许小幅可解释漂移）。
